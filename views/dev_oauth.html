OAuth API

A single client you can reuse for web, mobile and CLI apps.

Client credentials

Treat the client secret like a password. Anyone with it can impersonate your app.

Authorize URL

Send your users here. After consent they come back to your redirect_uri with a ?code=... you exchange for an access token.

{{publicUrl}}/oauth/authorize?client_id={{clientId}}&redirect_uri=YOUR_REDIRECT_URI&response_type=code&scope=profile+email&state=OPTIONAL

Token exchange

curl -X POST {{publicUrl}}/oauth/token \
  -d grant_type=authorization_code \
  -d code=THE_CODE \
  -d client_id={{clientId}} \
  -d client_secret={{clientSecret}} \
  -d redirect_uri=YOUR_REDIRECT_URI

User info

curl {{publicUrl}}/oauth/userinfo -H "Authorization: Bearer ACCESS_TOKEN"

Drop-in script & npm

Server-side:

// stigma.js
const { Stigma } = require('stigma-sdk'); // or just copy the helper below
const stigma = new Stigma({
  clientId: '{{clientId}}',
  clientSecret: '{{clientSecret}}',
  redirectUri: 'YOUR_REDIRECT_URI'
});
// stigma.handleCallback(req) -> { accessToken, user }
module.exports = stigma;

Browser / frontend (popup flow):

<script src="/static/js/stigma.js"></script>
<script>
  Stigma.signIn({
    clientId: '{{clientId}}',
    redirectUri: window.location.origin + '/auth/stigma/callback'
  }).then(user => {
    console.log(user); // { sub, name, email, phone, given_name, family_name }
  });
</script>
