⚠ Important: Service accounts have no Drive storage quota of their own. You must upload into a folder that belongs to a real Google account or a Shared Drive. The Folder ID below is required.

Setup instructions

1
In Google Cloud Console, create a service account and download its JSON key file.
2
In Google Drive, create a folder where backups will be stored.
Option A — Regular folder: Right-click → Share → add the service account email as Editor.
Option B — Shared Drive: Add the service account email as a Shared Drive Member (Content manager or higher).
3
Copy the Folder ID from the Drive URL:
https://drive.google.com/drive/folders/THIS_PART_IS_THE_ID
4
Paste the JSON key and Folder ID below and click Save.
{{#showForm}}
The folder must be shared with your service account email. Without this, uploads will fail (service accounts have no storage quota).
